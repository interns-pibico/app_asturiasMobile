## Mecanismo (ya implementado, genérico)

| Capa | Código |
|---|---|
| `services/poi.py` | `tipo: str \| None = None` + `AND TRIM(p.tipo) = :tipo` |
| `routers/api/pois.py` | `tipo: str \| None = Query(default=None)` |
| `explorar.js` — `fetchPage` | `if (catFilterTipo) url += \`&tipo=${catFilterTipo}\`` |
| `explorar.js` — tags click | `catFilterTipo = tag.dataset.tipo; reloadWithFilter()` — en `updateFilterPanel()` |
| `explorar.js` — reset | `catFilterTipo = ''` en `switchCategory()` |

## Flujo completo

1. `/explorar/24?cat=ocio` → `updateFilterPanel('ocio')` rellena panel con 8 tipos
2. Toca "Museo" → `catFilterTipo = 'museum'` → `reloadWithFilter()`
3. `fetchPage(0)` → URL = `.../api/pois/24?categoria=ocio&tipo=museum`
4. Backend devuelve solo museos + `X-Total-Count: 2`
5. "Cargar más" funciona con filtro activo
6. "Todos" → `catFilterTipo = ''` → recarga sin filtro
7. Cambio de categoría → `switchCategory()` resetea `catFilterTipo = ''`
