# Sesión 2026-03-12 13:06 — Captura de nombre del usuario en AstuGuía

## Objetivo
Implementar captura del nombre del usuario en el monigote AstuGuía para personalizar la experiencia. El nombre se persiste en `sessionStorage('astuguia_player_name')` y se comparte entre book.html y explorar.html.

## Cambios implementados

### `app/static/js/guia-book.js`
- `state.playerName` añadido al estado del wizard
- `s0.text` ahora incluye la pregunta del nombre en el mismo texto: "¡Qué pasa paisanu! … ¿Cómo te llames?"
- `showNameCapture()` nueva función — muestra input + botón "¡Dale!" sin typewriter propio (el input aparece al terminar el typewriter de s0)
- `showStep()` detecta `stepId === 's0'` y llama `showNameCapture` en lugar de `renderChoices`
- `showResult()` personaliza el texto con `${state.playerName}, ` si existe

### `app/static/js/guia-chat.js`
- `_awaitingName` variable de módulo (bool)
- `showInitialGreeting()` — si historial vacío: saluda con nombre (si existe en sessionStorage) o pregunta el nombre (`_awaitingName = true`)
- `openChatMode()` llama `showInitialGreeting()` al abrir
- `handleSend()` intercepta el primer mensaje si `_awaitingName`: guarda nombre, responde "¡Encantau de conocete!", retorna sin llamar a la API

### `app/static/css/guia.css`
- `.guia-name-row` — flex row para input + botón
- `.guia-name-input` — estilo compacto (font-size: 12px, padding: 5px 8px)
- `.guia-name-row .guia-btn` — `width: auto; flex: 0 0 auto` para que el botón no ocupe todo el ancho

## Flujos completos

**Camino A — Wizard primero:**
1. s0 typewriter: "¡Qué pasa paisanu! … ¿Cómo te llames?" → input + botón "¡Dale!" aparecen al terminar
2. User escribe "Pelayo" → sessionStorage guardado
3. "¡Encantau de conocete Pelayo! ¿Búscote un rincón nel Paraíso?" → "¡Empezar aventura!" → s1
4. [wizard completo] → "💬 Pregunta más" → `openChatMode()`
5. Chat vacío → "Hola Pelayo, ¿Qué ye lo que quies saber?"

**Camino B — Chat primero:**
1. Click monigote → `openChatMode()`
2. Chat vacío, sin nombre → "Hola, ¿Cómo te llames?", `_awaitingName=true`
3. User escribe "Pelayo" → `handleSend()` intercepta → guarda → "¡Encantau de conocete Pelayo! ¿Qué ye lo que quies saber?"
4. Conversación normal con API

## Bugs corregidos durante la sesión
- Input y botón demasiado grandes en el diálogo colapsado → `.guia-name-row .guia-btn { width: auto }` + input compacto
- Dos typewriters encadenados (presentación + pregunta nombre) daban sensación de prisa → unificados en `s0.text`
